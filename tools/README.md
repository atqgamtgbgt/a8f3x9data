# データ品質チェック（初期導入）

日本語表示の翻訳漏れや、ランキングの集計対象数の不一致を検知するための読み取り専用スクリプトです。

```bash
python tools/audit_data_quality.py
```

標準ライブラリのみを使用し、CSV・JSONの内容は変更しません。

- `output/autohome/*/config_*.ja.csv` の日本語列、列数、別名ファイルの一致を確認
- `output/market/autohome_factory_monthly.json` の月別掲載社数、合計値、重複順位・メーカー名を確認
- 不正なCSV構造や合計不一致は **ERROR** として終了コード1
- 掲載社数の不一致や翻訳列の空欄は **WARN** として報告

## 今後の対応

このスクリプトはブラウザ画面の中国語を直接検査するものではありません。画面表示側の言語統一とUIの自動テストは別の変更で進めます。

掲載社数が50社と100社の月をまたいで合計比較するときは、同じ集計対象にそろえるか、対象数を明示してください。日本語CSVの `.ja.csv` と `_ja.csv` は使用箇所を調査するまで削除しないでください。
