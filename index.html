    2026年 9月
    「旺季不旺」— 小売161.8万台（−28.0%・前月比+5.0%）、ICE車−43%の一方でNEV小売浸透率は67%と過去最高
    ▶
    • 9月小売161.8万台、前年比 −28.0% / 前月比 +5.0%。1-9月累計1,333.4万台 −21.7%。最大の特徴は「旺季不旺」で、伝統的な「金九」の成色が大きく不足。存量の奪い合いの中でICE車の需要が激しく萎縮した
    • 降幅が際立った要因：①中秋休暇が9月下旬にずれ込み中秋週の販売が弱い、②前年9月は一部の省で補助終了前の駆け込みがあり高基数、③高油価（年初来のガソリン価格は累計2,375元/トン上昇）、④AI需要によるメモリ・チップの価格高騰と供給逼迫でNEV新車の投入が鈍い
    • 9月卸売254.9万台 −8.9% / 前月比 +8.1%。輸出の激増で卸売伸び率が小売を19pt上回る「内冷外熱」。国内卸売が少なく在庫削減が進み、チャネル圧力は明確に改善
    • 9月生産259.0万台 −9.1% / 前月比 +10.3%で年内最高。高級 −24%、合弁 −29%、中国系 −1%
    • 9月輸出（完成車＋CKD）91.7万台 +73.7% / 前月比 +3.2%、メーカー販売の36%（前月38%、25年同期19%）。NEVが輸出の60.8%（+21pt）。2ヶ月続けて7月のピークを下回り、平穏期に入りつつある
    • 産販在庫：卸売が生産を4.1万台下回り、国内卸売は国内小売を1.4万台上回る。1-9月の業界在庫は−68万台（25年同期 −25万、24年 −88万、23年 −13万）
    • NEV卸売浸透率 65.4%（前年比 +12pt）— 中国系75.5% / 高級55.4% / 合弁16.3%。伝統車卸売 −32% に対しNEV +12%、伸び率差は44pt。小売浸透率は67.0%（+9.1pt、前月比 +1.7pt）で過去最高、中国系84.5%、高級44.9%、合弁15.9%
    • 動力別：ICE車小売−43%（純ICE −49%、HEVは +25%）、NEV小売108.4万台 −16.7%。ICE車は中国系 −47%・合弁 −42%・高級 −41%と一様に高油価の打撃を受けた
    • 国別：中国系113万台 −25%（前月比 +5%）でシェア69.8%（+2.8pt）。主流合弁31万台 −36%（前月比 +2%）（独12.2% −2.0pt、日10.7% −0.9pt、米6.3% +0.5pt）。高級17万台 −29%でシェア11%（−0.2pt）
    • 級別：小売 −28%・卸売 −9%で「内冷外熱」。入門級の消費が大きな打撃を受け、A級・A00級セダンが低調、A0級セダンと高級車種が主力。SUVは高級が強い
    2026年 8月
    閑散期の底で「筑底蓄力」— 小売154.1万台（−23.6%・前月比+5.5%）、輸出は高水準で平穏期へ
    ▶
    • 8月小売154.1万台、前年比 −23.6% / 前月比 +5.5%。1-8月累計1,171.6万台 −20.7%。「総量は弱い回復、前月比は改善、構造は極端な二極化」で、閑散期の尾部で底固め（筑底蓄力）の段階
    • 前年割れの要因は多元的：高油価、以旧換新新政の規範強化と乗用車補助の縮小、上流の値上げ。根底には消費能力と購買意欲の低さがある
    • 乘聯会予測チームの7月予測指数19%に対し、8月中旬に評価した7月の満足度は17%。8月の予測指数12%は歴史的な底部水準で、9月中旬の満足度は改善を見込む
    • 8月卸売235.3万台 −5.3% / 前月比 +4.5%。輸出の激増で卸売伸び率が小売を18.3pt上回る。国内卸売が少なく在庫削減が進み、チャネル圧力は明確に改善
    • 8月生産235万台 −4% / 前月比 +5.4%。9月の下押し圧力はさらに大きいとみる
    • 8月輸出（完成車＋CKD）88.8万台 +77.8% / 前月比 −4.2%、メーカー販売の38%（前月41%、25年同期20%）。NEVが輸出の58.4%（+18pt）。高速の前月比上昇が止まり、平穏期に入りつつある
    • 産販在庫：卸売が生産を0.5万台上回り、国内卸売は国内小売を7.6万台下回る。1-8月の業界在庫は−71万台（25年同期 −30万、24年 −76万、23年 −20万）と在庫削減が際立つ
    • NEV卸売浸透率 64.2%（前年比 +12pt）— 中国系74.3% / 高級53.1% / 合弁15.7%。伝統車卸売 −29% に対しNEV +17%、伸び率差は50pt近く。小売浸透率は65.2%（+9.9pt）で、中国系83.9%、高級38.9%、合弁13.4%
    • 国別：中国系108万台 −19%（前月比 +4%）でシェア69.9%（+4.1pt）。主流合弁31万台 −35%（前月比 +5%）（独12.5% −2.1pt、日10.9% −1.4pt、米5.6% ほぼ横ばい）。販売の少ない合弁メーカーは徐々に活力を回復
    • 級別：小売 −23%・卸売 −5%で「内冷外熱」。入門級の消費が大きな打撃を受け、A級・A00級セダンが低調、A0級セダンと高級車種が主力

    📋 2026年1-7月 リチウム電池輸出 解説（崔東樹） 原典 ↗

    2026年1-7月のリチウム電池輸出は580億ドルに達し、前年同期比+41%。7月単月は94億ドル（+33%）を維持した。国内の新エネ乗用車小売が前年比で約20%減るなか、国内は値上げ・海外は値下げで「価格下落・数量増」の輸出が好調。新興市場の開拓と中核市場の深耕で、国内の環境変化に対応している。

    価格は底入れ。ドル建て輸出単価は2023年の2.73万ドル/トン → 2024年2.01万ドル/トン → 2025年1.57万ドル/トン → 2026年（1-7月）1.52万ドル/トン（−8%）。下落幅は2024年の−26%・2025年の−22%から大きく縮小し、7月は1.55万ドル/トンと前年同月比+2%に転じた。人民元建ては10.5万元（−11%）、7月は10.6万元（−3%）で、4-7月の輸出還付率引き下げ後の値下げ幅は前年より明確に改善した。

    太陽能電池は伸び悩み。1-7月の太陽能電池輸出は372億ドル（+20%）、7月は43億ドル（−4%）。年間では2022年928億ドルのピークから2023年876億ドル → 2024年612億ドル → 2025年564億ドル（−8%）と縮小が続き、業界の内巻が深刻。

    地域構成 — 欧州が牽引、対米は急縮小。最大市場のEUは2026年に需要シェア42%前後（前年比+2pt）。対米国シェアは10%へ急減（−6pt）。7月の主な輸出先はドイツ13.0億ドル・米国7.7億ドル・オランダ6.6億ドル・インド6.0億ドル・ベトナム5.7億ドル。1-7月の増加額はオランダ（+22.4億ドル）・インド（+16.3億ドル）・日本（+15.4億ドル）が大きい。

    対米国の詳細。7月の対米輸出は8.6億ドル・5.9万トン、単価は1.46万ドル/トン（前年同月比+26%）で、2025年10-11月から明確に改善。人民元建ては9.93万元/トン（+20%）。米国のAIブームによる電力・蓄エネ需要の急増は、中国からの電池輸出にはまだ結びついていない。

    2026年が想定を下回った短期要因
    1. 政策の節目：年初の以旧換新は入門車の基準引き上げ・補助縮小でBEVの条件も厳しくなった。2025年末の購入税優遇の終了で需要が先食いされ、年初のNEV小売が大きく落ちた。
    2. 地政学と油価：記事によると、3月の米国・イランの戦争で原油価格が高騰し、ICE車の使用コストが急上昇した。
    3. AI投資のコスト波及：メモリー価格の高騰でNEVの採算が悪化。電力需要で銅など、蓄電需要で炭酸リチウムが高騰し、半導体・素材・電池までコストが上がった。
    4. 以旧換新の効果逓減：効果は2024年が最大で、買い替え意欲の強い層はすでに購入済み。2026年は消費意欲が低く、政策の効き目が落ちた。
    政策の先食いと油価は外から来た一時的な要因、AIのコスト波及は2026年に特有の要因とみている。長期の構図（過去10年のボックス圏）は変わっておらず、下に外れた分だけ戻りの余地が大きいという見立て。
    2027年を支える6つの要因
    1. 購入税優遇の終了前の駆け込み：NEV浸透率が上がった分、2025年より効果が大きい。
    2. 春節が消費の大年：2027年は2月5日（2026年は2月16日）で、節前の購入が年間を支える。
    3. 油価の影響が弱まる：原油価格が戻れば、抑えられていたICE車の需要が出てくる。
    4. 炭酸リチウムの下落：10万元前後と2026年の高値からほぼ半減し、電池価格が下がる。
    5. 在庫サイクルの反転：2026年の大幅な在庫削減が2027年は小さくなり、メーカーの国内出荷の伸びは小売を上回る。
    6. 新車供給の回復：2026年は5m超の大型車が新車の79%（2024年44%）と大型化が急進。コストが落ち着けば各価格帯に競争力のある新車が出る。
    前提は、政策と環境が想定外に変わらないこと。メーカー間の分化はさらに進むとみている。
